# Выбор часов разряда накопителя по архиву АТС

Расчётный пример для предынвестиционной оценки промышленного накопителя энергии. Проверяет, как выбор одного или двух часов разряда влияет на снижение нагрузки в расчётный час при одинаковом расходе энергии.

## Данные и условия

Использованы опубликованные АТС часы Кемеровской области для ПАО «Кузбассэнергосбыт». Часы разряда выбираются по сентябрю 2025 года; результат проверяется на 22 опубликованных днях сентября 2026 года. Тестовые данные не участвуют в выборе часов. При равной частоте выбирается меньший час. Источники файлов, контрольные суммы и параметры сохранены в `manifest.json`.

Учебная нагрузка составляет 3 МВт, мощность батареи 1 МВт, ёмкость 2 МВт·ч. На каждый день выделен одинаковый бюджет разряда 1 МВт·ч: 1 МВт в один час или по 0,5 МВт в два отдельных часа. В начале каждого дня нужный запас энергии уже доступен.

## Результат

| Режим | Часы АТС | Попадания в пик | Среднее снижение нагрузки в час пика | Доля от результата при известном пике |
|---|---|---|---|---|
| Один час | 17 | 18 из 22 | 0,818182 МВт | 81,82% |
| Два отдельных часа | 17 и 15 | 21 из 22 | 0,477273 МВт | 47,73% |

При двух часах попаданий больше, но мощность разряда в каждом часе вдвое меньше. Поэтому снижение нагрузки оказалось меньше при том же расходе энергии. Результаты по дням находятся в `daily.csv`, сводка в `summary.csv`.

## Повторение расчёта

Проверено с Python 3.12. Зависимости зафиксированы в `requirements.txt`.

```console
python -m pip install -r requirements.txt
python primer-pika.py
```

Программа читает два сохранённых файла АТС, проверяет даты и часы, пересоздаёт CSV и `manifest.json` и выводит сводку. Для самого расчёта подключение к сети не нужно.

## Границы результата

Расчёт относится к одному региону и одному месяцу. Зарядка, потери, износ, стоимость электроэнергии, годовая экономия и окупаемость здесь не рассчитаны. Проценты в таблице относятся к снижению нагрузки относительно контрольного расчёта с заранее известным пиком, а не к снижению полного счёта за электричество. Часы сохранены в обозначениях АТС без пересчёта часовых поясов. Этот пример задаёт проверочный сценарий для будущего оптимизатора и не подтверждает точность будущего прогноза.

Источник данных: [АТС, фактические часы пиковой нагрузки](https://www.atsenergo.ru/results/market/calcfacthour).
